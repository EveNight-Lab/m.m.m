# PWA 아이콘 파일 필요

PWA가 제대로 작동하려면 다음 아이콘 파일들이 필요합니다:

- `icon-192.png` - 192x192 픽셀
- `icon-512.png` - 512x512 픽셀  
- `apple-touch-icon.png` - 180x180 픽셀 (iOS용)

이 파일들을 `public/` 폴더에 추가해주세요.

온라인 도구를 사용하여 아이콘을 생성할 수 있습니다:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- https://favicon.io/

**참고**: 현재 아이콘 파일이 없어서 PWA 매니페스트 오류가 발생할 수 있습니다. 
임시로 간단한 아이콘을 추가하거나, 개발 중에는 브라우저 콘솔의 경고를 무시해도 됩니다.
